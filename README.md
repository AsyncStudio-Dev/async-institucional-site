# Async Studio Landing Page

Website institucional bilingue da Async Studio, construido com Next.js App Router, React, TypeScript e Tailwind CSS.

## Comandos

```bash
npm install
npm run dev
npm run build
npm run start
```

## Estrutura

- `src/app`: rotas do Next.js App Router.
- `src/views`: componentes de pagina reutilizados pelas rotas.
- `src/content`: textos em portugues e ingles.
- `src/assets`: assets importados pela aplicacao.
- `public`: favicons, manifest, robots e imagem social.
- `src/components`: componentes reutilizaveis de layout e UI.
